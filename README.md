# 충치벌레 쫓아내기

아이폰 전면 카메라로 아이 얼굴을 비추면, 입을 "아~" 벌렸을 때 이 위에 귀여운 애벌레들이 나타나 냠냠 먹습니다. 칫솔로 닦으면 벌레들이 놀라서 입 밖으로 도망가고, 정해진 시간이 끝나면 이가 반짝이며 별 스티커를 받습니다.

- 대상: 만 3~4세. 무섭지 않게 만들었습니다 (구멍·상처 표현 없음, 끝은 항상 칭찬).
- 앱 설치 없이 웹 주소로 실행합니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
- 카메라 영상은 휴대폰 안에서만 처리하고, 어디에도 보내지 않습니다. 서버·계정·광고·분석 도구가 없습니다.

## 1. 인터넷에 올리기 (한 번만)

카메라는 **https 주소**에서만 켜집니다. 이 폴더 전체를 무료 정적 호스팅에 올리면 됩니다. 폴더 안 파일 구조를 그대로 유지해 주세요.

### 방법 A. GitHub Pages (무료, 추천)

1. GitHub에서 새 저장소를 만듭니다 (예: `brush-bugs`, Public).
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**.
3. **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**.
4. 1~2분 뒤 `https://<GitHub 아이디>.github.io/brush-bugs/` 주소가 생깁니다.

### 방법 B. Netlify Drop

1. 컴퓨터 브라우저에서 https://app.netlify.com/drop 에 들어갑니다 (무료 계정 필요).
2. 이 폴더를 통째로 끌어다 놓으면 https 주소가 바로 생깁니다.

## 2. 아이폰에서 열기

1. 위에서 만든 주소를 **Safari**로 엽니다. (카카오톡 안에서 열었다면 메뉴의 "Safari로 열기")
2. 공유 버튼 → **홈 화면에 추가**. 다음부터는 아이콘으로 바로 실행됩니다.
3. 처음 **시작!**을 누르면 카메라 허용을 물어봅니다. **허용**을 눌러 주세요.
4. 처음 한 번은 준비 파일(약 15MB)을 받느라 몇 초 걸립니다. 이후에는 휴대폰에 저장되어 빨리 열립니다.

카메라 허용을 매번 묻는 게 번거로우면: Safari 주소창 왼쪽 페이지 메뉴(가가/aA) → **웹 사이트 설정 → 카메라 → 허용**.

## 3. 사용 방법

1. 휴대폰을 세면대 거울 옆에 세워 두고, 아이 얼굴이 화면의 동그라미에 들어오게 합니다 (30~50cm).
2. "입을 아~" 안내에 맞춰 입을 벌리면 벌레들이 나타납니다.
3. 양치 시간(기본 2분)을 4구역으로 나눠, 별이 반짝이는 곳을 닦으라고 안내합니다. 닦는 움직임이 보이면 벌레가 더 빨리 도망갑니다.
4. 움직임을 못 알아봐도 시간이 지나면 벌레는 모두 도망갑니다. 아이가 실패하는 일은 없습니다.
5. 끝나면 별 스티커가 쌓이고, 첫 화면에서 일주일 기록을 볼 수 있습니다.

**보호자 설정**: 오른쪽 위 ⚙︎ 버튼을 1초 이상 **길게** 누르면 열립니다 (아이가 실수로 못 열게). 양치 시간 1/2/3분, 목소리, 효과음, 인식 상태 보기를 바꿀 수 있습니다.

## 4. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 소리가 안 나요 | 무음 모드를 끄고 볼륨을 올려 주세요. 목소리 대신 화면 아래 자막도 나옵니다. |
| "Safari로 열어 주세요"가 떠요 | 카카오톡·인스타그램 안의 브라우저에서는 카메라가 안 될 수 있습니다. Safari로 여세요. |
| 카메라가 검게 나와요 | 홈 화면 아이콘 대신 Safari에서 주소로 직접 열어 보세요. |
| 벌레가 안 나와요 | 입을 더 크게 벌리고, 밝은 곳에서 얼굴이 동그라미에 들어오게 해 주세요. 설정의 "인식 상태 보기"를 켜면 입 윤곽과 수치가 보입니다. |
| 오래된 아이폰에서 느려요 | iOS 16.4 미만에서는 느린 방식으로 자동 전환됩니다. iOS 15 이상이면 동작하지만 최신 기기일수록 부드럽습니다. |

## 5. 파일 구성

```
index.html             화면과 스타일
app.js                 앱 로직 (카메라, 얼굴 인식, 벌레, 양치 타이머, 스티커)
sw.js                  오프라인 캐시
manifest.webmanifest   홈 화면 앱 정보
icons/                 앱 아이콘
vendor/                MediaPipe 얼굴 인식 엔진 0.10.35 (Apache-2.0)
models/                MediaPipe 얼굴 인식 모델 face_landmarker.task (Apache-2.0)
```

- 얼굴 인식 모델은 `models/face_landmarker.task`에 들어 있어 앱 파일과 함께 받습니다. 이 파일이 없으면 앱이 아래 구글 공식 주소에서 받습니다.
  https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
- 파일을 고친 뒤에는 `sw.js` 맨 위의 `CACHE` 이름 숫자를 올려야 휴대폰에 새 버전이 반영됩니다.
